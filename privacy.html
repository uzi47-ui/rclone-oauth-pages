Privacy Policy

Rclone Drive Sync — last updated 14 September 2026

This policy explains how Rclone Drive Sync (the "app") accesses, uses, stores, and shares information when it connects to a Google Account. The app is a private automation operated by a single individual for their own files; it has no other users and no public interface.

1. What Google user data the app accesses

The app requests a single Google Drive permission: https://www.googleapis.com/auth/drive.file.

This scope allows access only to files and folders that the app itself creates, plus files the user explicitly opens with the app. The app cannot see, read, list, modify, or delete any other files in the user's Google Drive. It does not request access to Gmail, Contacts, Calendar, Photos, location, or any other Google service.

2. How the app uses that data

Data is used for one purpose only: transferring files generated on the operator's own server into a folder in the operator's own Google Drive, and keeping that folder in sync. The app performs no analytics, profiling, advertising, or marketing use of the data.

3. Storage and retention

Files live in the operator's Google Drive account, under the user's own control. OAuth credentials (a refresh token) are stored locally on the operator's own server with restricted file permissions, and are never transmitted anywhere except to Google's token endpoint for authentication. Data is retained for as long as the operator chooses to keep the files; the operator can delete them at any time, and removing the app's access in the Google Account permissions page revokes the stored credentials.

4. Sharing and third parties

Google user data is not sold, rented, or shared with any third party. The app transfers data only between the operator's server and Google's own APIs. No sub-processors, no advertising networks, and no external analytics services are involved.

5. Machine learning

Google user data accessed by this app is not used to develop, improve, or train generalized or non-personalized artificial-intelligence or machine-learning models.

6. Security

Credentials are stored on the operator's private server, and access to that server requires authenticated access controlled by the operator. The app uses HTTPS for all communication with Google APIs.

7. Changes to this policy

If this policy changes, the updated version will be published at this URL with a revised "last updated" date.
