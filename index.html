Rclone Drive Sync

A private, single-user automation tool.

What this app does

Rclone Drive Sync is a personal automation running on my own home server (a Raspberry Pi). It uploads files that the server generates — reports, documents, and archives — into a folder in my own Google Drive so that I can access them from other devices.

The tool is built on rclone, an open-source command-line program for managing cloud storage. There is no public sign-up, no other users, and no web front end: the only person who ever authorizes it is the owner.

How it accesses Google Drive

It requests the drive.file permission only. That means it can see and manage only the files and folders it created itself. It cannot read, list, modify, or delete anything else in the Drive account.

Data handling

Files are transferred directly between the server and Google Drive. Nothing is sent to any third party, and no Google user data is sold, shared, or used to train machine-learning models. Full details are in the privacy policy.
